설정 원본은 config/*.json이다. 파생 Rainmeter INI나 Windhawk 런타임 설정을 독립 설정 원본으로 사용하지 않는다. 관리자 권한 상승·Explorer 재시작·로그아웃·재부팅은 별도 승인을 받는다. S01이 막혀도 다른 단계를 계속하며 센서 값을 만들지 않는다.

설정 변경은 검증 → 이전값 백업 → 원자적 저장 → 실제 적용 → 확인 → 실패 복원 순서다. 기존 v2.1 전체 롤백을 v2.4 복구로 자동 호출하지 않는다.

## 최종 승인 대기

HWiNFO 자체 관리자 실행은 승인되어 실제 센서를 확인했다. 별도의 영구 관리자 로그온 작업 `GUNT-HWiNFO-Sensors-v24`는 추가 승인을 요청했으며, 승인 전에는 등록하지 않는다. 스크립트는 scripts/register-hwinfo-startup.ps1에 준비했다. 등록 이후에도 실제 로그오프/로그온 시험은 별도 승인·검증 대상이다.
