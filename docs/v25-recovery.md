# v2.5 복구 안내

## 먼저 선택할 복구

1. 아직 저장하지 않은 값: **변경 버리기**. 실제 파일은 바뀌지 않습니다.
2. 직전 설정 적용: **직전 적용 취소**. 해당 키가 외부에서 바뀌었다면 덮어쓰지 않고 오류를 표시합니다.
3. 오래된 설정 한 개: **진단 및 복구 → 설정 백업 선택 → 차이 확인 → 선택 설정 복원**. 전체 프로젝트·배경을 초기화하지 않습니다. 이 복원도 Undo 대상입니다.
4. 작업공간 전환: **프로필 → 이전 상태 복원**. 모니터 표시·compact·수동 배경 정지 정책만 복원하며, 한 번만 소비합니다. 현재 배경 선택과 저장 화면 위치는 유지합니다.
5. 구성 요소 문제: 진단에서 해당 구성 요소만 열기/복원/새로고침합니다. Explorer를 자동 재시작하지 않습니다.

## 코드·실행 파일을 이전 버전으로

최초 `pre-v25-ux-overhaul` 체크포인트에 원본 449개 파일의 SHA256을 기록했고, 중간 `v25-foundation`에 461개를 기록했습니다. 실제 경로는 개인 `state/*-checkpoint.json`에 있습니다. 최종 적용 파일 목록은 `state/v25-applied-files.json`입니다. 이 파일들은 공개 저장소에 포함하지 않습니다.

PowerShell에서 프로젝트 폴더를 열고 **먼저 검사만** 합니다.

```powershell
.\scripts\rollback-v25-ux.ps1 -Component ControlCenter -WhatIf
.\scripts\rollback-v25-ux.ps1 -Component TopBar -WhatIf
.\scripts\rollback-v25-ux.ps1 -Component All -WhatIf
```

실행은 제어 센터에서 변경을 정리하고 닫은 뒤 동일 명령의 `-WhatIf`를 제거합니다. 관리자 권한·Explorer 재시작은 요구하지 않습니다.

- `ControlCenter`: 이전 제어 센터 소스·빌드 스크립트·실행 파일. 추가 partial 파일은 별도 백업으로 이동합니다. 남아 있는 새 소스 때문에 구형 빌드가 깨지는 것을 막습니다.
- `TopBar`: 이전 프로젝트 상단 바 소스·실행 파일·빌드 해시. 프로젝트 소유 상단 바만 정상 종료/재시작하며 Windows Explorer는 건드리지 않습니다.
- `All`: 위 둘과 이번 공유 설정 라이브러리·지원 스크립트. 사용자 JSON·프로젝트·즐겨찾기·배경·Rainmeter·Windhawk는 초기화하지 않습니다. 문서·검사 코드·개인 데이터는 남습니다.

원본 백업 해시와 현재 적용 파일 해시가 모두 일치해야 실행합니다. 이후 소스 변경이 있거나 백업이 없으면 덮어쓰지 않고 중단합니다. 복구 직전 코드를 별도 백업하고 실패 시 그 파일을 다시 복원하도록 시도하되, 실제 실행 후 화면·기능 확인은 필요합니다. 이번 검증에서는 `-WhatIf` 사전 검사만 실행하고 전체 코드 롤백은 실행하지 않았습니다.

## Dock 보류

실제 적용 시험 뒤 Explorer 교체가 관찰되어 자동 적용을 보류했습니다. 현재 스타일·크기는 시험 전으로 돌아왔습니다. `state/dock-live-apply-hold.json`은 원인이 해소되고 별도 검증되기 전 유지합니다. 보류 파일을 지우는 것만으로 문제가 해결됐다고 판단하면 안 됩니다. 안전 보류 상태에서는 Dock 값을 읽고 Windhawk를 열 수 있으며 JSON 쓰기와 모드 재적용은 거부합니다.

## 개인 정보·현재 배경

갤러리 관찰·프로필 복원은 과거 Gojo 배경을 다시 선택하지 않습니다. 현재 Lively 선택을 유지합니다. 문제 해결에 이전 전체 `rollback.ps1`을 무조건 사용하지 마세요. 진단 내보내기는 기본 가림을 하지만 공유 전에 내용을 확인하세요. 개인 프로젝트 경로·센서 매핑·실행 로그·배경 미디어·체크포인트는 Git 제외 대상입니다.
