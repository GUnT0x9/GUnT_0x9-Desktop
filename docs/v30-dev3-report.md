# GUnT_0x9 Desktop 3.0.0-dev.3 — UI Polish & Performance Results

## 1. 전체 상태와 기준

**2026-10-20, 개발 프리뷰·검토용.** `feat/v30-ui-foundation`의 실제 로컬/원격 기준 `ce664bf`와 dev.2를 확인하고 이어 구현했다. main/v2.x 이력을 보존했다. 정식 3.0 출시 또는 모든 UI·환경의 검증 완료를 의미하지 않는다.

에이전트 호스트는 WSL2다. `/init`으로 Windows 11 Home 26200의 PowerShell 5.1과 기존 Framework64 C# 빌드 도구를 호출해 실제 WPF 앱을 실행했다. 직접 PE 실행의 `Exec format error`와 앱 실패를 구분했으며 시스템의 실행 등록을 바꾸지 않았다.

최초 체크리스트는 공통 보조창 → 작은 창 주요 동작 → 프로젝트/세션 행 → 갤러리 반복 작업 → 팝업 → 실제 측정/캡처 → 공개 문서였다. 아래에 수행 범위와 남은 문제를 구분한다.

## 2. AI 패턴과 실제 문제

불필요한 새 카드·배지·색을 넣지 않았다. 실제 없었던 그라디언트/글로우를 제거했다고 주장하지 않는다. 기존 Midnight Purple 토큰·공식 브랜드·선택 테두리와 기본 포커스 의미를 유지했다.

## 3. Control Center와 보조창

공통 `UxTheme.Dialog/Confirm`, 편집창의 본문/하단 구조를 추가했다. 프로젝트 등록·개발 기본값·도구·기존 세션/규칙 편집 경로는 같은 생성기를 사용한다. OS 파일/폴더 선택기는 기존 네이티브 동작을 유지한다. 긴 필드 이름은 줄바꿈한다.

닫기/X/취소 시 중첩 입력도 지문 비교에 포함하고 저장·버리기·계속 편집을 제공한다. 유효성 오류는 본문 끝에 숨지 않도록 저장 동작 위에 표시한다. 실제 작은 창에서 오류 후 계속 편집·수정 후 재저장을 검사했다.

960 DIP 미만에서 탐색 폭/로고/버전 표시를 줄이고 그룹 제목을 감춘다. 목적지 이름·선택 표시·기존 19개 경로는 유지한다. 긴 목록의 탐색 스크롤은 남는다. 일반 적용/버리기는 미저장 변경이 있을 때만 표시한다.

## 4. Developer Setup

행은 이름/최근 사용과 유형/Git의 두 줄이다. Git 실패를 깨끗한 저장소로 표시하지 않는다. 즐겨찾기는 행 내부에 유지하며 그 이중 클릭이 실행으로 전파되지 않는다. 선택·키보드·문맥 메뉴 경로와 비동기 선택 저장을 보존했다. 빈 영역 우클릭은 이전 행 실행 메뉴를 열지 않는다.

Inspector를 프로젝트 정보와 개발 환경으로 구분하고 주요 5개 도구를 우선 배치한다. 작은 창에서는 그 도구를 위에 유지한다. WSL 미지정인 Codex/OpenCode는 비활성/설명으로 표시한다. 기존 탐지·Git·데이터베이스·실행 서비스는 재구현하지 않았다.

## 5. Development Sessions

큰 창의 목록/편집기와 작은 창의 프리셋 선택 상자를 같은 선택 모델에 연결했다. 저장·버리기·저장 후 시작은 제목 아래에 유지한다. 단계 속성·사용·이동·제거, 분리된 실행 미리보기와 접힌 전체 이력을 보존했다.

단계 순서/사용 변경 시 기존 행과 열린 속성 컨트롤을 재사용한다. 등록 도구/동작 종류 변경과 프로젝트 환경 변경은 필요한 속성을 다시 만든다. 페이지 진입에 읽은 프로젝트 환경은 명시적 편집 후 갱신하며 떠날 때 미리보기 타이머·단계 참조를 정리한다.

실제 펼친 단계 이동은 3회×20표본의 회차 중앙값 기준 **25.047→8.001ms, −68.1%**였다. 최초 세션 페이지 열기·전체 렌더·실행 엔진이 68% 빨라졌다는 뜻은 아니다. [조건과 원자료 범위](v30-performance.md#실제-세션-편집-동작)를 참고한다.

## 6. Wallpaper Gallery

상단 미리보기/적용/즐겨찾기와 검색·화면 선택을 정리했다. 재생/엔진 동작은 펼쳐 접근한다. 목록이 남은 높이를 사용하고 바깥 세로 스크롤을 끈다. 1–6열·16:9·현재 배치·즐겨찾기·선택·키보드 탐색과 기본 재활용 가상화를 유지한다.

템플릿을 창 수명 안에서 재사용하고 같은 열/데이터의 중복 행 재구성을 건너뛴다. 동일 썸네일 작업을 합치고 동시 디코딩 2개·240px·64개 캐시를 유지한다. 메타데이터 한 조회를 배치 정보에도 재사용한다. 현재 배경·화면 배치를 바꾸거나 별도 영상 렌더러를 만들지 않았다.

## 7. Command Palette와 Quick Panel

팔레트는 검색 상단·문맥/실행/키 안내 하단을 고정하고 결과만 스크롤한다. 두 줄 결과에 실제 대상 프로젝트를 표시하며 빈 결과의 실행을 막는다. 입력 중 중간 미리보기 갱신을 줄이고 같은 질의를 건너뛴다. 검색/목록에서만 Enter를 실행 키로 처리해 도구 버튼의 Enter와 충돌하지 않게 했다. 닫기 후 소유 창 복귀를 실제 키 입력과 UIA로 확인했다.

360 DIP 빠른 패널은 경로를 한 줄과 툴팁으로 표시하고 개발 동작·프로필을 줄였다. 표시한 프로젝트와 실행 직전 대상이 바뀌면 다시 열어 확인하도록 한다. WSL 미설정 동작을 성공처럼 표시하지 않는다. 진행 중 닫기 보호·안전한 바깥 클릭·Escape·모니터 작업 영역 처리를 유지했다.

## 8. 나머지 UI와 모니터

개요·진단의 센서 중복 품질 문구와 센서 페이지 반복 제목을 정리했다. 센서 목록 읽기는 백그라운드에서 실행하며 늦은 응답은 현재 페이지·요청 세대가 맞을 때만 반영한다. 실제 HWiNFO 중지/결측과 비활성 연결을 화면에서 확인했다. 센서를 첫 화면으로 직접 시작할 때는 `Application.Run` 전이라 UI 동기화 컨텍스트가 없을 수 있었다. 비동기 완료를 명시적으로 Dispatcher에 전달하도록 보정하고, 이동 IPC 없이 직접 시작하는 Windows 회귀 검사를 추가해 통과했다. 센서 공급자·샘플링·매핑 저장 의미는 유지한다.

프로필·디스플레이·Windhawk·정보·WSL·스마트 자동화도 실제로 열어 기존 레이아웃·한글·리소스·빈 상태를 확인했다. 자동화는 사용자의 실제 빈 목록이었고 규칙 엔진 발동 조합까지 시각 검증한 것은 아니다.

Rainmeter는 숫자·축 글꼴/네트워크 정렬 소스를 이미 배포된 표현과 맞췄다. 배포본은 숨긴 미터의 Y=0 보정이 있으므로 원본 전체를 덮지 않고 표시 속성만 적용한다. 실패한 첫 전체 교체를 복구한 뒤 **위치·크기·보호 파일 6개 해시 일치**를 확인했다. 이미 배포본에 적용된 글꼴도 있어 새 시각 변화/성능 절감으로 과장하지 않는다. 측정식·Lua·실제 사용자 배치·센서 엔진은 변경하지 않았다.

WinForms의 기존 폰트·비트맵·아이콘 소유/해제 코드는 검토 후 유지했다. 같은 코드의 자원 처리를 dev.3의 새 성능 효과로 계산하지 않는다.

## 9. 성능과 퇴행

[성능 보고](v30-performance.md#dev3--2026-10-20-전후-비교)에 새 dev.2 기준과 dev.3의 5회 교차 중앙값/범위, 메모리/CPU, 별도 세션 이동 3회 결과를 기록했다. 중간 빌드·실패·이전 날짜 수치를 최종 표에 섞지 않는다. 최종 메모리 증가와 중간 후보의 팔레트 +31% 등 실행별 증가/변동도 공개한다. 전체 시작·CPU·장시간 누수 개선은 주장하지 않는다.

## 10. 실제 캡처와 개인정보

[화면 검증 기록](v30-screenshots.md#dev3--2026-10-20)에 주요 10개·추가 5개 페이지와 3종 크기, 위젯/보조창 전후를 기록했다. 현재 연결 화면은 **1개·2880×1800·175%**다. 저장된 과거 다중 화면 배치를 현재 실물 검증으로 세지 않는다.

공개 이미지는 [시각 기록](visual-history.md#v300-dev3--ui-polish--optimization)과 [manifest](images/releases/manifest.json)에 있다. dev.3 4개·보존 dev.2 비교 2개를 독립 예제 설정에서 얻었다. RGB 재인코딩·메타데이터 제거 후 최종 파일을 다시 열어 확인했다. 예제 데이터라 불투명 가림이 필요하지 않았다. 개인 경로·장치 정보·권리 미확인 갤러리 미디어·원본/로그는 게시하지 않는다. 현재 화면을 과거 날짜의 상태로 표시하지 않는다.

## 13. Git과 게시

구현/측정 도구와 공개 문서를 나누어 커밋한다. `284d783`(UI/반복 작업), `21b7539`(모니터 표시), `de265fe`(재현 검사), `60af707`(보조창 오류 피드백), `78ddf11`(센서 비동기 요청 표현), `451e1cc`(센서 첫 화면 Dispatcher·회귀 검사)로 구분했다. 이 문서를 포함한 최종 문서 커밋은 Git 이력에서 확인할 수 있다. 일반 push 후 로컬 HEAD와 원격 개발 브랜치 해시가 같을 때만 게시 완료로 보고한다. main 병합·이력 재작성·강제 push는 하지 않는다.

## 14. 남은 작업

1. 팔레트 초기 구성·추가 UI의 메모리 비용을 프로파일링하고 긴 탐색/다양한 데이터로 다시 측정.
2. 프로필 미리보기의 원시 True/False·긴 ISO 시각, 좁은 루트 목록 경로 잘림, 기본 접기 glyph 등 표현 추가 정리.
3. 전체 키보드/스크린리더·고대비·큰 글꼴·다른 실제 DPI와 다중 화면 재연결.
4. 전체 3.0 안정판 검증과 설치/배포는 별도 이정표. Scenes·창 관리자·새 에이전트/엔진을 이번 작업에 추가하지 않음.

현재 배경, 사용자 데이터·설정, Dock 자동 적용 보류와 File Explorer Styler 비활성을 유지했다. Explorer를 재시작하거나 관련 불안정성을 조사하는 작업으로 범위를 넓히지 않았다.
