# 3.0 실제 화면 검증

## 현재 상태

이번 실행에서 캡처한 Windows UI 이미지: **0개**.

일반·권한 상승 `powershell.exe` 실행 모두 `Exec format error`로 실패했다. 연결된 화면 수와 배율도 조회하지 못했다. 175% DPI와 물리 다중 모니터 검증을 완료로 표기하지 않는다. v2.x 기존 스크린샷은 역사 자료로만 유지한다.

## 준비한 수집 도구

실제 Windows PowerShell 대화형 세션에서 다음을 실행한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-v30-ui.ps1 -Label after -Samples 5
```

도구는 기존 창이 열려 있으면 중단하고, 직접 연 창의 화면 탐색·캡처만 수행한다. 도구 실행 버튼·설정 적용·배경 변경·Explorer 재시작은 요청하지 않는다. 종료 후 기존 창 위치 기록을 복원한다. 창이 정상 종료되지 않으면 강제 종료하지 않는다.

출력은 `screenshots/v30-after/`와 `logs/v30-ui-after.json`에 저장한다. 이 자료는 실제 경로가 포함될 수 있어 Git에서 제외한다. 문서에 넣을 이미지는 실제 검토 후 개인정보를 확인한 자료만 별도로 선택한다.

## 검토 대기 목록

- 19개 실제 목적지와 명령 팔레트·빠른 패널.
- 요청 크기 780×560, 1180×800, 1500×900 DIP. 작업 영역이 작으면 실제 픽셀 크기와 제한 여부를 확인한다.
- 실제 OS 배율 100/125/150/175/200%. 도구는 배율을 변경하지 않으며 캡처마다 실제 DPI를 기록한다.
- 개발 세팅의 3열/2열/단열, 접힌 루트 설정 접근, 경로 잘림과 툴팁, 빈 결과.
- 세션 목록·단계 편집·실행 요청 미리보기·개별 결과.
- 팔레트 검색 결과와 대상 표시, 방향키·Enter·Escape·포커스 복귀.
- Tab/Space, 비활성 컨트롤, 키보드 포커스, 미저장 변경 보호, 한국어 폰트.
- 실제 썸네일·비어 있는 갤러리·즐겨찾기·배치 표시.

파일 저장 성공은 시각 검토 통과가 아니다. 빈 화면·잘린 창·다른 상태를 저장했다면 거절하고 다시 캡처한다. 시각 결함을 고친 후 같은 크기와 데이터로 재검토해야 한다.
