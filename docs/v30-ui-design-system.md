# 3.0 UI 디자인 시스템

상태: `3.0.0-dev.2` 개발 프리뷰. 주요 화면을 실제 Windows 175%에서 렌더링·검토했다. 다른 배율·스크린리더·고대비는 추가 검증 대상이다.

## 기반

기존 `Views/UxStyles.cs`를 확장한 `UxTheme`가 Control Center와 DeveloperPopup의 브러시·공통 ResourceDictionary를 제공한다. 새로운 UI 프레임워크나 병렬 스타일 서비스는 없다. 기존 `config/theme.json`의 Midnight Purple 팔레트·사용자 글꼴 선택은 유지한다.

| 의미 | 값 |
|---|---|
| 창 배경 | `#0E0E12` |
| 보조 표면 | `#15151C` |
| 구분선 | `#23232B` |
| 기본 글자 | `#F4F4F5` |
| 보조 글자 | `#A1A1AA` |
| 선택·포커스·주요 동작 | `#A78BFA` |
| 보조 브랜드 보라 | 기존 `#C084FC`, 장식용 추가 사용 없음 |

상태색은 실제 상태를 전달할 때만 사용한다. 선택은 가는 테두리와 굵기로 함께 나타낸다. 배경색·보라색만으로 선택을 구분하지 않는다.

## 글꼴과 간격

- 본문은 기존 S-Core Dream 설정을 존중한다. Manrope, Malgun Gothic, Segoe UI를 대체 글꼴로 사용한다. 팝업도 같은 순서를 사용한다.
- 시스템 심볼 글꼴과 네이티브 아이콘은 변경하지 않는다. 공식 마스코트·작은 워드마크·정보 페이지 전체 로고를 유지한다.
- 페이지 제목 21 DIP, 일반 본문 13–14 DIP, 보조 정보 12 DIP, 탐색 그룹 11 DIP.
- 간격은 4/8/12/16/24/32 DIP를 기준으로 한다. 기존 페이지의 일부 5/7/10/14 DIP 값은 남아 있으며 후속 시각 보정 대상이다.
- 일반 버튼 최소 높이 34 DIP, 체크 입력 최소 높이 32 DIP, 버튼 모서리 4 DIP.
- `UseLayoutRounding`, `SnapsToDevicePixels`를 셸·팝업에 적용한다.

## 구성 요소

| 용도 | 구현 |
|---|---|
| 기본/보조 동작 | 공통 Button 템플릿, Apply는 강조 테두리 |
| 검색·문자 입력 | 공통 TextBox, 대비 있는 캐럿·포커스 테두리 |
| 선택 입력 | 공통 ComboBox, 기존 선택 값·저장 의미 유지 |
| 설정 행 | 기존 AddField: bool 체크, 한정 선택 드롭다운, 정확한 수치 입력 |
| 상태 행 | StatusRow: 이름·실제 상태·관련 동작, 하단 구분선 |
| 섹션 제목 | SectionHeader: 얇은 구분선·15 DIP 제목 |
| 프로젝트/명령/규칙/단계 | 재활용 가상화 ListBox와 데이터 템플릿 |
| 문맥 메뉴 | 공통 ContextMenu 표면, 기존 실행 경로 연결 |
| 빈 상태·오류 | 실제 작업 근처 설명 또는 기존 상태 영역, 새 장식 없음 |
| 진행 | 비동기 외부 조회에만 실제 조회 중 메시지 |

선택 입력의 접근성 이름과 단계 편집 이름을 제공하며, 실제 화면에서 포커스·선택·비활성을 검토한다. 전체 Tab 순서·스크린리더·고대비 검증은 남아 있다. 제목·텍스트 크기를 줄여 다열 화면을 강제하지 않는다.

## dev.2 구성 규칙

프로젝트는 카드가 아닌 메타데이터 행으로, 세션은 접을 수 있는 본문 단계로, 배경은 독립 객체 타일로 표현한다. 썸네일은 16:9 영역을 사용하고 원본을 늘려 찌그러뜨리지 않는다. 설정의 단순 필드에 별도 카드를 추가하지 않는다. 접힌 속성과 로그는 열 때 생성한다.
