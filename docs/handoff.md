# 프로젝트 인계

실제 프로젝트: `%USERPROFILE%\GUNT-Desktop`. 현재2.1 Midnight Purple 적용 상태이며 처음부터 다시 설치하지 않습니다. WSL 임시 staging보다 Windows 프로젝트의 config·state·logs가 현재 상태의 기준입니다.

## 완료·유지할 기능

정확한 고죠80% 정적 배경, 큰 네이티브 Dock·트레이, 한국어 AppBar5개 메뉴, Rainmeter 시스템 모니터, 한국어 작업 표시줄 시계, 실제 알림·달력 테마, 로그인 VBS 복원, 파일·레지스트리 백업·rollback이 있습니다. 고정 앱과 개발 도구 설정은 보존합니다.

## 인계 후 수정

- 시작 복원: 실행 파일 누락·응답 없음·프로젝트 소유 경로를 최종 health와 Errors에 반영. 별도 임시 프로젝트에서4개 누락 감지 통과.
- 라이브 복원: 준비·검증·패키지·실행 준비 오류에서 정적 대안. 엔진 미설치·비활성이 현재 기본값이며 실제 재생은 미검증.
- 검증: 선택 밝기·표시 모드를 설정에서 읽고 메뉴 MSAA 기록과 알림 기록을 분리. 구문 및 정상 경로 재검증.

## 우선순위

1. 현재 시각·기능·기존 백업 유지.
2. 실제 다음 로그인·연결 변경 시 복원 관찰. 사용자 승인 없이 재부팅·로그아웃·권한 상승 금지.
3. 라이브 엔진이 실제 필요할 때만 설치·절전 정책·성능 검증. 설정 JSON의 목표 정책을 적용된 엔진 기능으로 오인하지 않기.
4. GPU·온도·추가 효과는 별도 요구와 신뢰할 수 있는 센서 경로가 있을 때 검토.

개발할 때 변경 전 config·앱 설정을 별도 백업하고 필요한 부분만 수정합니다. scripts/verify.ps1, verify-dock.ps1, verify-startup.ps1, verify-recovery.ps1과 logs/v21-*.json을 기준으로 검증합니다. 이미 통과한 검사는 해당 코드나 환경이 바뀔 때 다시 실행합니다. 실제 원상복구와 전원 동작은 수행하지 않았습니다.

전체 적용·제한·버전·측정은 [작업 보고서](v21-report.md), 설정은 [설정 안내](customization.md), 복구는 [복구 안내](recovery.md)에 있습니다.
