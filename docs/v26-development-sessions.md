# v2.6 개발 세션

## 템플릿

| 기본 ID | 처음 제공하는 동작 |
|---|---|
| ai-coding | VS Code + 프로젝트 기본 AI CLI. 초기 기본값은 Codex |
| opencode | VS Code + OpenCode |
| web | VS Code + 프로젝트 호스트에 따른 터미널 |
| review | VS Code + 등록된 GitHub URL. URL이 없으면 건너뜀 |

작업공간 프로필은 프로젝트 또는 세션에서 지정한 경우에만 적용합니다. 실제 현재 값→새 값을 시작 요약에 표시합니다. 기본 세션은 편집·이름 변경·복제할 수 있고 삭제는 막습니다. 사용자 세션은 확인 후 삭제할 수 있습니다.

## 편집과 실행

- 동작 추가·제거·사용 전환·위/아래 이동, 순차/독립 요청, 터미널 호스트, 작업공간 프로필.
- 순차는 앞 요청이 반환된 뒤 다음 실행 요청을 보내며, 서버 준비·IDE 로딩 완료·CLI 대화 종료를 기다린다는 의미가 아닙니다.
- 독립은 각 동작을 병렬 요청하고 동작별 실패·건너뜀·전달 결과를 각각 기록합니다.
- 먼저 프로젝트·경로·배포판·도구 목록·프로필 차이를 확인하는 시작 요약을 보여 줍니다.
- `command`는 기존 프로젝트의 사용자 명령을 별도 동의한 경우만 실행합니다. 기본 템플릿에는 개발 서버 자동 실행 명령이 없습니다. 자동화 경로에서는 프로젝트 명령을 허용하지 않습니다.
- 시작 중인 요청의 동시 실행을 잠그고, 같은 프로젝트/세션은 요청 완료 이후에도 5초간 연속 시작을 막습니다. 다른 터미널·편집기는 종료하지 않습니다.

## 기록·다시 시작

최근 실행 50개에 프로젝트 ID, 프리셋 ID, 시작/종료 기록, 요청한 도구와 개별 결과만 보관합니다. 소스·터미널 내용·대화·셸 명령 이력을 수집하지 않습니다.

**이전 개발 세션 다시 시작**은 마지막 프리셋 동작과 유효 개발 설정의 스냅샷을 미리본 뒤 다시 실행합니다. 프로젝트의 최신 등록 경로는 다시 검증합니다. AI 대화·프로세스·서버 상태를 복원하지 않습니다.

**개발 세션 종료 기록**은 사용자가 작업 종료를 기록하는 기능입니다. 도구 종료를 감시하거나 기존 프로그램을 강제 종료하지 않습니다. 해당 기록이 자동화의 `session-ended` 이벤트입니다.
