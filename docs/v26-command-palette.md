# v2.6 명령 팔레트·빠른 패널

## 열기

- 상단 바 **GUnT_0x9 → 빠른 패널 / 명령 팔레트**. 기존 브랜드 메뉴를 보존합니다.
- 전역 기본 키 **Ctrl+Alt+Space**. **명령어 관리**에서 Ctrl+Shift+Space 또는 사용 안 함으로 바꿉니다.
- 기존 제어 센터 내부 **Ctrl+K** 또는 설정한 Ctrl+Shift+P도 같은 팔레트를 엽니다.
- Flow Launcher의 Alt+Space와 Windows Search는 변경하지 않습니다. 기존 전역 키와 충돌하면 등록 실패를 기록하고 가로채지 않습니다.

## 검색

한글 이름·영문 별칭·대소문자 무시·부분 문자열·순서 기반 fuzzy 검색을 사용합니다. 위/아래, Enter, Escape를 지원하고 즐겨찾기·최근 명령을 로컬에 저장합니다.

| 입력 | 의미 |
|---|---|
| cx | 현재 프로젝트 Codex, 고정된 내장 별칭 |
| oc | 현재 프로젝트 OpenCode, 고정된 내장 별칭 |
| dev | 개발 세팅 |
| VS Code / vscode | 편집기 실행 |
| 프로젝트 이름 + codex | 해당 등록 프로젝트의 Codex 실행 |
| 모니터 / 배경 / 센서 / 진단 | 기존 GUNT 동작·화면 |

명령어 관리에서 실제 명령을 골라 사용자 별칭을 추가합니다. 대소문자 차이·내장 별칭 충돌은 거부하며 조용히 덮어쓰지 않습니다. 별칭 삭제와 명령 즐겨찾기를 지원합니다. 별칭이 임의 셸 명령 문자열을 실행하는 기능은 아닙니다.

## 빠른 패널

제어 센터 전체 창을 만들지 않고 같은 실행 파일의 소형 창만 엽니다. 현재 프로젝트 이름·전체 경로·프로필을 표시합니다. 프로젝트가 없거나 없어졌으면 개발 실행을 막고 프로젝트 선택으로 안내합니다. 표시 이후 현재 프로젝트가 바뀌었다면 다시 확인하게 하며 다른 폴더를 조용히 실행하지 않습니다.

Codex·OpenCode·VS Code·폴더·기본 개발 세션, 모니터·배경 제어, 프로필·설정·명령 팔레트를 연결합니다. 기본 세션도 먼저 실제 실행 요약을 확인하고 시작합니다. Escape 또는 유휴 상태 바깥 클릭으로 닫으며, 요청 처리 중에는 중간 종료를 막습니다. 커서가 있는 화면의 작업 영역·배율로 배치하고 음수 좌표를 허용합니다.

별도 검색 서버·상주 팔레트 프로세스는 없습니다. 열려 있는 팝업은 같은 앱의 별도 단기 창으로 실행될 수 있고 닫으면 종료합니다. 상단 바가 전역 키 등록을 담당합니다. Flow 플러그인 자동 설치·불안정한 내부 API 연동은 하지 않았습니다.

## 구현

`Services/CommandRegistry.cs`의 정의·별칭·검색·실행을 공유합니다. 도구 실행은 모두 `DesktopService.LaunchDeveloper`와 WSL 인수 생성기로 모입니다. `DeveloperPopup`은 표시·선택·확인만 담당하며 별도 Codex 실행 코드를 복사하지 않습니다. MainWindow의 키·탐색은 기존 dirty 보호를 유지합니다.
