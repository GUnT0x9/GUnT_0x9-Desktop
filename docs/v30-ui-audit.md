# 3.0 UI 점검

## dev.2 실제 검토

2026-10-19 Windows 네이티브 앱에서 주요 화면 10개와 3개 창 크기를 캡처하고 직접 검토했다. 실제 화면은 1개·175%다. 소스만 검사했던 dev.1의 한계를 Windows `/init` 명시 실행으로 해소했다. [실제 화면 검증](v30-screenshots.md)을 따른다.

확인한 결함은 어두운 배경의 검은 Expander 제목, 검색 안내 부재, 중복 패딩으로 큰 입력, 작은 데이터에서 큰 빈 목록, 세션 편집 분산, 긴 행 형태 갤러리였다. 공통 템플릿·상태 행·본문 단계 편집·타일 배치를 실제 코드에 적용하고 다시 캡처했다.

대형 그라디언트·광채·가짜 터미널은 기존 앱에 없었다. 없던 장식을 제거했다고 집계하지 않는다. 공식 브랜드와 의미 있는 선택·상태·썸네일은 유지하고 반복 문장·빈 표면·중복 동작을 줄였다.

실제 WPF 상호작용 검사에는 큰 목록 가상화, 즐겨찾기 저장, 단계 순서·사용·대상 저장, 미저장 보호와 캐시 상한을 포함한다. 전체 스크린리더·고대비·다른 DPI의 접근성 통과를 뜻하지 않는다.
