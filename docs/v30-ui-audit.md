# 3.0 UI 점검

## 증거와 한계

2026-10-19 `3ae33e2` 소스와 최신 원격 상태를 확인했다. 현재 WSL 실행 환경의 Windows 실행 파일 직접 실행은 일반·권한 상승 모두 `Exec format error`다. Windows 창에 연결할 수 없어 이번 실행의 실제 스크린샷은 0개다. 따라서 아래 내용은 **소스 점검 결과**이며 실제 화면 감사 완료를 뜻하지 않는다. 기존 v2.5/v2.6 이미지도 이번 감사 증거로 재사용하지 않았다.

`kill-ai-slop` 스캐너를 전후 실행했으나 웹 중심 규칙이므로 WPF 품질 점수나 제거 개수로 사용하지 않았다. 사용자 지정 공식 브랜드·기존 폰트는 유지했다.

## AI-slop 판단

기존 앱에는 이미 평면 Midnight Purple 표면이 있었고, 대형 그라디언트·보라 광채·가짜 터미널·장식 지표를 확인하지 못했다. 없는 문제를 제거했다고 보고하지 않는다. 이번 변경은 반복 제목, 팝업의 큰 제목, 고정 적용 버튼, 중복 스타일과 긴 로그의 비중을 줄이는 데 집중했다. 의미 있는 프로젝트·배경 목록과 실제 상태는 삭제하지 않았다.

## 접근성 확인 범위

소스상 키보드 포커스 테두리, 선택 굵기, 접근성 이름, 목록 키 동작, Escape 및 처리 중 닫기 보호가 존재한다. 실제 UIA 노출·Tab 순서·스크린리더·포커스 복귀·Korean 글리프·고대비 모드·175% 배율은 확인하지 못했다. 시각 검토는 캡처 후에만 완료 처리한다.
