# v2.3 구현 체크리스트

상태는 소스 구현 / 실제 적용 / 기능 / 화면 / 성능으로 나눠 기록합니다. 현재 Windows 프로젝트가 기준이며 이전 보고서의 완료 표시는 재검증 없이 이어받지 않습니다.

| 순서 | 단계 | 상태 | 남은 검사 |
|---|---|---|---|
| 0 | 현재 상태·Lively·기준 백업 | 검증됨 | 실제 로그인은 마지막에 별도 표기 |
| 1 | Floating Dock v3·오른쪽 Dock | 기능·화면 검증됨 | 성능은 최종 비교 표본에서 측정 |
| 2 | 상단 바 v3 | 기능 검증됨 | 제어 센터 정식 연결은 5단계에서 확인 |
| 3 | System Monitor v3 | 진행 중 | 그래프 7개 기준값·전체 버튼·실제 센서 |
| 4 | Windhawk 통합 | 시작 전 | 개별 모드·기본 Windows 기능 |
| 5 | Control Center | 시작 전 | 빌드·모든 지원 설정·트랜잭션·프로필 |
| 6 | 자동화·절전·멀티 모니터 | 시작 전 | 현재 Lively 보존·정책·복구 |
| 7 | 최종 QA·문서 | 시작 전 | 시나리오별 표본·최종 화면 |

지원하지 않는 온도·전력 센서는 사용할 수 없음으로 표시합니다. 관리자 권한 상승·Explorer 재시작·로그아웃·재부팅은 자동 실행하지 않습니다.

### 한글 표시 결함 수정 — 2026-10-16

Lua 인코딩·섹션 이름 충돌·보기 전환을 수정하고 실제 간단히/자세히 화면 및 새로고침 유지 검증을 완료했습니다. 이 항목의 완료가 System Monitor v3 전체나 v2.3 전체 완료를 뜻하지 않습니다. 상세: [한글 수정 기록](monitor-korean-fix.md).
