# 글꼴 조사·배포

공식 S-Core Dream OTF9종을 메모리에서 검사했다. 모두 기본 ASCII·한글완성형11172자를 포함하며 브랜드의 수학문자는 없다. 숫자 폭은 동일하다. SCDream4의 이름은 Regular지만 OS/2 weight=200이므로 이름/실제 파일로 선택하고 임의 synthetic bold를 쓰지 않는다.

UI S-Core Dream5 Medium14DIP, 제목6 Bold15DIP, 보조4 Regular12.5DIP, 주요수치5 Medium22DIP. 영문 전용 Manrope Medium12.5–14DIP. 혼합문구와 측정 숫자는 S-Core를 사용한다. Manrope는 기본 숫자가 가변 폭이다. Inter는 이점이 작고 Outfit은 표제 성격이 강하며 Plus Jakarta는 별도 추가 필요가 적었다. 후보4종은 OFL1.1이다.

현재 사용자용 S-Core4/5/6·ManropeRegular/Medium만 등록한다. 원본과 라이선스 보존, 시스템 기본 글꼴/트레이 글리프는 변경하지 않는다. S-Core 파일 변경·폰트 자체 판매 금지. 재배포 시 저작권 안내 포함. 설치 전 기존 등록/파일을 기록하고 롤백은 이번 신규 항목만 대상으로 한다.

브랜드 코드포인트: 1D4D6 1D4E4 1D4F7 1D4E3 005F 1D7CE 1D501 1D7D7. Cambria Math와 Segoe UI Symbol의 cmap·Windows 렌더 및 WPF GlyphTypeface에서 누락 없음. NFKC 정규화 금지. Windows 글꼴 파일은 번들하지 않는다.
